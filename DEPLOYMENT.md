# Deployment

Long-running Node process that watches Prenotami for appointment slots and
pings Telegram when one appears. Built to run unattended on a Linux server.

## Requirements

- **Node.js 18+**
- **Chromium system libraries.** Playwright downloads the browser binary
  itself, but not its shared-lib deps. On a Debian/Ubuntu host run
  `npx playwright install-deps chromium` once. On NixOS see the note at
  the bottom.
- **~300 MB disk** (node_modules + downloaded chromium).
- **~500 MB RAM at rest**, peaks ~800 MB during a check.
- **Outbound HTTPS** to `prenotami.esteri.it`, `iam.esteri.it`,
  `api.telegram.org`.

## Files the runtime needs

- `dist/` — build output, generated by `npm run build`
- `node_modules/` — dependencies, generated by `npm ci`
- `.env` — secrets (see `.env.example`)
- `screenshots/` — created at runtime

## Install

```bash
git clone https://github.com/brunodmsi/Prenotami-Passport.git
cd Prenotami-Passport
npm ci
npx playwright install chromium
npx playwright install-deps chromium   # Debian/Ubuntu; skip on NixOS
cp .env.example .env                   # fill in credentials & Telegram
npm run build
```

## Configuration

Full reference in `.env.example`. Minimum viable `.env`:

```
PRENOTAMI_EMAIL=...
PRENOTAMI_PASSWORD=...
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_IDS=...
```

Defaults are polite: ~1 check/hour with jitter, surrender after 3 errors,
2–12h backoff on detected blocks. **Do not tighten `POLL_MIN_SECONDS`
without a residential proxy** — you'll get IP-throttled within hours.

## Run

```bash
npm start
```

Exits 1 only after 10 consecutive restart failures. Otherwise runs until
a slot is found (then exits cleanly so you can go book it) or forever.

## systemd unit

`/etc/systemd/system/prenotami.service`:

```ini
[Unit]
Description=Prenotami appointment checker
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=prenotami
WorkingDirectory=/opt/prenotami
EnvironmentFile=/opt/prenotami/.env
ExecStart=/usr/bin/node dist/src/index.js
Restart=on-failure
RestartSec=60
StartLimitIntervalSec=3600
StartLimitBurst=3
# Chromium leaks on very long runs; recycle once a day.
RuntimeMaxSec=86400

[Install]
WantedBy=multi-user.target
```

Install:

```bash
sudo useradd --system --home /opt/prenotami prenotami
sudo rsync -a --exclude=.git --exclude=screenshots/*.png ./ /opt/prenotami/
sudo chown -R prenotami:prenotami /opt/prenotami
sudo chmod 600 /opt/prenotami/.env
sudo systemctl daemon-reload
sudo systemctl enable --now prenotami.service
journalctl -u prenotami -f
```

## NixOS note

Playwright's downloaded Chromium is a glibc-linked binary that won't run
on the default NixOS loader. Two options:

1. **OCI container** (simplest). Declare via
   `virtualisation.oci-containers.containers.prenotami` using a base
   image like `node:20-bookworm-slim`, bake `npx playwright install-deps`
   into the Dockerfile, mount `.env` as a secret. This matches a
   declarative nix-config style without fighting linker issues.
2. **Bare NixOS.** Enable `programs.nix-ld.enable = true;` and add the
   `playwright-driver.browsers` package (from nixpkgs) to the service
   environment, or use `buildFHSUserEnv` to wrap `npm start`.

## Troubleshooting

- **`login email field not found on <url>`** — the IAM page HTML changed.
  Run `HEADLESS=false npm run printPage` locally, inspect the new field,
  update `LOGIN_EMAIL` / `LOGIN_PASSWORD` in `src/constants/locators.ts`.
- **`login submit did not leave IAM`** — wrong credentials, captcha, or
  the submit button selector stopped matching. The thrown error includes
  the on-page error text.
- **Telegram silent** — confirm `TELEGRAM_BOT_TOKEN` and
  `TELEGRAM_CHAT_IDS` are set; fetch
  `https://api.telegram.org/bot<TOKEN>/getUpdates` to verify the chat id.
- **Block backoff never ends** — by design, the loop surrenders after 3
  consecutive errors/blocks. systemd's `Restart=on-failure` +
  `RestartSec=60` brings a fresh process up a minute later.
